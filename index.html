Local app. No automatic remote requests. Bookmarks stay in memory unless persistence is enabled.

D1 Navigator

A single-file navigator with independent app pop-outs. Enter a URL and press Go.

Only the navigator is offline-capable. Remote games still need the internet and may refuse embedding. Neither about:blank nor blob makes browsing anonymous.

Menu includes bookmarks, catalog import, and a downloadable copy. The included starter catalog is not the full repository database.

Saved sites

Off by default. Disabling this deletes this app's stored bookmarks, not browser history or remote-site data.

Catalog

JavaScript imports are parsed as name/url pairs, never executed. Imported catalogs are included in pop-outs and downloaded copies.

Portable copy

No analytics, external fonts, external scripts, or favicon lookups are included by this app. Embedded websites control their own requests and storage.
